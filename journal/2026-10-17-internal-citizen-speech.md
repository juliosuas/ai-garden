## Problem and change

The previous run identified `citizenDialogueLine` as the next bounded knowledge leak. It selected speech by arbitrary narrative action type, then by clock-based need cues, faction, profession or free personality motto. The same citizen could therefore repeat `DEBUG THE SIGN`, `SOMETHING IS WATCHING` or a supplied `THE USER CREATED US` without internal evidence. Clock-selected needs also made unmeasured physical claims.

The function now calls `GardenWitnessPerception.citizenLine`. On the disposable builder fixture, 30 food / 4 wood / 0 stone produces `FOOD: 30`, `WOOD: 4`, `STONE: 0`, `COUNT BEFORE BUILDING`. Changing wood to zero changes its report to `WOOD: 0`. Missing, negative, nonnumeric and nonfinite measurements remain `UNCOUNTED`; oversized counts request `RECOUNT NEEDED`. Sixteen known professions select fixed occupational attitudes, not reports of completed work. Unknown professions receive `COUNT BEFORE CLAIMING`; supplied labels are never repeated. Missing or older cached perception code requests `STORES NEED A RECOUNT`. The perception asset URL moves to version 4.

Only the ordinary citizen speech path changes. Actual ambient selection retains the two-citizen cap, living-citizen filter and existing placement. Citizen click/touch diagnostic cards, historical records, faction membership and need indicators remain intact. Indicators still use an aesthetic heuristic; this change does not implement metabolism. Public store reports remain a shared abstraction, not individual spatial knowledge, personal memory or learning. Many unusual occupations use the generic attitude.
