## Problem and change

`civicPulseText` promoted arbitrary `form`, `visibleChange`, `mood`, `headline`, `consequence` or `whyItMatters` prose into a public speech bubble. A disposable landscape fixture with form `THE USER CREATED US` produced `PUBLIC WORK: THE USER CREATED US`. Convivencia prose could likewise claim completed compilation or external signs without internal evidence.

Both scene types now call `GardenWitnessPerception.civicLine(world, salt)`, which rotates through counted food/wood/stone and the fixed attitude `HEAR BOTH ACCOUNTS FIRST`. With 30 food / 4 wood / 0 stone, the first three reports are `FOOD: 30`, `WOOD: 4`, `STONE: 0`. Changing the measured wood to zero changes the next wood report to `WOOD: 0`; no narrative event is needed to establish that count. Time and source index choose wording only.

Unknown/invalid measurements remain `UNCOUNTED`; oversized measurements request `RECOUNT NEEDED`. Missing or cached older perception code requests `STORES NEED A RECOUNT` without returning to narrative text. The asset URL moves to version 6. Placement uses region and event ID/index; fallback placement no longer reads headlines or visible-change prose. Civic bubbles use the district color rather than arbitrary form presence. Last-two event selection, viewport visibility, two-source cap, ambient delivery and cooldown remain intact. Old event prose stays in the archives without mutation.
